# BossPlugin - Продвинутая система боссов для Minecraft 1.21.4 Paper

## Описание
Плагин добавляет крутую систему боссов, похожую на RealWorld, с уникальными способностями, эффектами и наградами.

## Особенности
- **5 уникальных боссов** с разными способностями:
  - 🔥 **Огненный Лорд** (Fire Lord) - Blaze с огненными атаками
  - ⚡ **Грозовой Титан** (Storm Titan) - Husk с ударами молний
  - 🌑 **Темный Рыцарь** (Dark Knight) - Zombie в нетеритовой броне
  - ❄️ **Ледяная Королева** (Ice Queen) - Stray с ледяными атаками
  - 👁️ **Древний Страж** (Ancient Warden) - Warden с мощнейшими атаками

- **Уникальные способности** у каждого босса:
  - Взрывы
  - Удары молний
  - Лечение
  - Телепортация
  - Огненные/ледяные волны
  - Баффы скорости

- **Система наград**:
  - Уникальные предметы за убийство каждого босса
  - Большой опыт
  - Специальные эффекты при смерти

- **Эффекты от атак боссов**:
  - Поджог (Огненный Лорд)
  - Замедление и слабость (Грозовой Титан)
  - Слепота (Темный Рыцарь)
  - Заморозка (Ледяная Королева)
  - Темнота и урон душе (Древний Страж)

## Команды

| Команда | Описание | Права |
|---------|----------|-------|
| `/boss spawn <название> [мир] [x] [y] [z]` | Призвать босса | bossplugin.admin |
| `/boss list` | Показать список всех боссов | bossplugin.admin |
| `/boss kill <название\|all>` | Убить босса | bossplugin.admin |
| `/boss help` | Показать справку | bossplugin.admin |
| `/summonboss <название>` | Быстро призвать босса рядом | bossplugin.admin |

## Названия боссов для призыва:
- `firelord` - Огненный Лорд
- `stormtitan` - Грозовой Титан
- `darkknight` - Темный Рыцарь
- `icequeen` - Ледяная Королева
- `ancientwarden` - Древний Страж

## Примеры использования:

```bash
# Призвать Огненного Лорда рядом с собой
/boss spawn firelord

# Призвать Грозового Титана по координатам
/boss spawn stormtitan world 100 64 200

# Посмотреть список всех боссов
/boss list

# Убить всех активных боссов
/boss kill all

# Быстрый призыв Темного Рыцаря
/summonboss darkknight
```

## Установка

1. Скачайте плагин или соберите его через Maven
2. Поместите файл `BossPlugin.jar` в папку `plugins` вашего сервера
3. Перезапустите сервер
4. Настройте права доступа (по умолчанию доступны только OP)

## Сборка из исходников

```bash
cd BossPlugin
mvn clean package
```

Собранный файл будет находиться в `target/BossPlugin-1.0.0.jar`

## Требования
- Minecraft 1.21.4
- PaperMC (или совместимый форк)
- Java 21
